================================================================================
                     CalibGuard 文件审计  ——  使用说明
================================================================================

一、这是什么
--------------------------------------------------------------------------------
CalibGuard 是一个本地文件安全审计工具：把可疑的文件（脚本、代码、文本、压缩
包等）交给它，它会判断文件是否包含恶意意图，并给出四个等级的处理建议：
放行 / 可疑 / 拦截 / 转人工。

判定流程：本地模型（CodeBERT 微调 + 概率校准）先给出"恶意概率"，
  · 概率低于灰区下限  → 直接放行（不联网）
  · 概率高于灰区上限  → 直接拦截（不联网）
  · 落在灰区之间      → 可选的云端大模型复核（需要自己配置 API Key）

整个过程默认在本机完成；只有落在灰区的文件、且你开启了云端复核时，才会联网。


二、运行要求
--------------------------------------------------------------------------------
  · 操作系统：Windows 10 / 11（64 位）
  · 首次运行需联网（要自动下载运行环境，约几百 MB ~ 2.5 GB，按网速）
  · 磁盘空间：建议预留 3 GB 以上
  · 显卡：有 NVIDIA 显卡会自动加速；没有、或显卡较旧会自动用 CPU（慢一些，功能相同）
  · 不需要你自己安装 Python —— 首次运行会自动准备


三、快速开始（5 步）
--------------------------------------------------------------------------------
  1. 把压缩包【整个解压】到一个目录。
     注意：不要只把 CalibGuard.exe 单独复制出来 —— 它必须和旁边的文件放一起。

  2. 双击 CalibGuard.exe。

  3. 首次运行会自动准备运行环境（弹出"环境准备"窗口，通常 2~10 分钟）。
     窗口上会显示当前进行到哪一步，请耐心等待，不要关闭窗口。

  4. 准备完成后会自动打开浏览器，进入审计界面。若没有自动打开，
     启动窗口里显示了一个网址（形如 http://127.0.0.1:xxxxx），
     手动复制到浏览器打开即可。

  5. 以后再用：双击 CalibGuard.exe，几秒即可打开。

  · 关闭"CalibGuard"启动窗口 = 退出程序（浏览器页面同时失效）。


四、界面怎么用
--------------------------------------------------------------------------------
【提交文件】
  · 方式一：把文件【拖拽】到中间的虚线框，或点"选择文件"按钮（可多选）。
            这种方式会把文件复制一份到 uploads/ 目录再审计。
  · 方式二（高级）：展开"直接粘贴文件路径"，每行粘一个路径，
            直接审计原位置的文件，不产生副本。

【开始审计】
  点"开始审计"，界面会显示进度。多个文件会依次处理（不并行）。

【看懂结果卡片】
  · 大标签（最终结论，四色）：
        绿 放行       —— 未发现恶意迹象
        黄 可疑       —— 云端复核认为有可疑点，建议人工看看
        红 拦截       —— 判定为恶意，建议不执行/不打开
        灰 转人工     —— 云端复核不可用或结果不合法，建议人工判断
  · 标签右侧小字"门控: xxx" —— 本地模型给出的中间态
        放行 / 拦截 / 提交云端 LLM
  · 进度条 —— 校准后的"恶意概率"（0~100%）
  · "全文滑窗 N 段，早停：是/否" —— 推理统计
  · "特征命中" —— 命中的具体可疑项（危险 API、网络行为、凭据访问等）
  · 底部文字 —— 云端复核结论；若没配 Key 会显示"降级人工复核"


五、设置说明（右上角"设置"按钮）
--------------------------------------------------------------------------------
  1) 使用云端 LLM 复核
       总开关。关闭后不发起任何联网调用；落在灰区的文件改为按本地模型
       在 50% 处划分（>50% 拦截，否则放行）。

  2) API Key
       云端大模型的服务密钥（例如 DeepSeek 的 sk- 开头密钥）。
       留空 = 不使用云端复核。仅保存在本机 gui-settings.json，不写日志。

  3) Base URL
       云端接口地址，默认 https://api.deepseek.com

  4) 模型名称
       云端模型名，默认 deepseek-chat

  5) 送审内容（送什么给云端看）
       · 精炼证据：只送从文件里提取出的可疑项摘要（危险 API、网络行为、
         凭据访问、混淆编码、注入话术等）。省流量、快。
       · 文件原文：把文件正文送给云端（按下面的"投递方式"处理）。
         信息最全，但消耗更多 token。

  6) 投递方式（怎么送）
       · 截断        —— 只送前 N 个字符（可设置"截断大小"，默认 3000）
       · 滑窗        —— 把内容切成有重叠的多段，逐段送审，
                        结果取最严重的一段（可设置"滑窗大小"与"滑窗重叠"）
       · 一次性全部上传 —— 整段一次性送过去

  7) 灰区范围
       默认 0.15 ~ 0.85（下限、上限两个输入框）。
       概率 < 下限 → 放行；概率 > 上限 → 拦截；中间 → 才提交云端复核。
       注意：必须满足 0 < 下限 < 上限 < 1，否则保存会被拒绝并提示原因。

  · 保存时机：如果当前正在审计文件，设置会在"当前任务完成后"生效，界面会提示。


六、目录里都是什么
--------------------------------------------------------------------------------
  CalibGuard.exe          启动器（双击它）
  server.py               后端服务
  audit_service.py        审计任务封装
  requirements-gui.txt    运行环境依赖清单（首次运行按它安装）
  web/index.html          前端界面
  calibguard/             审计引擎
  models/                 模型 + 校准参数（可整体更换，见下）
  README.txt              本说明

  运行后会自动出现（不属于发布内容）：
  .venv/                  运行环境（删掉后可自动重建）
  logs/                   运行日志（出问题时可查看 server.log / bootstrap.log）
  reports/                审计报告（json + md）
  uploads/                拖拽方式提交的文件副本
  gui-settings.json       你保存的设置（含 API Key）


七、更换模型
--------------------------------------------------------------------------------
  1. 退出 CalibGuard（关掉启动器窗口）。
  2. 用一个新版本的【整个 models 文件夹】覆盖本目录的 models 文件夹。
     其中 codebert_finetuned/ 与 calibration_params.json 必须来自同一次训练，
     不要混搭。
  3. 重启 exe。若顶部没有出现红色横幅，说明模型与校准参数配套正常。

  （界面底部的"帮助"折叠块里也有同样的说明。）


八、常见问题
--------------------------------------------------------------------------------
  Q1: 第一次启动很慢，卡在"安装依赖"？
  A : 正常。首次要下载运行环境（torch 等），从几分钟到十几分钟都属正常，
      取决于网速。只有第一次慢，之后是秒开。

  Q2: 提示"环境准备失败"？
  A : 多半是网络问题。点击窗口里的【重试（使用镜像）】按钮重试；
      仍失败可打开 logs\bootstrap.log 查看具体原因。

  Q3: 上次还好，这次打不开了 / 之前中断过？
  A : 环境可能损坏。把 exe 旁边的 .venv 文件夹整个删掉，再双击 exe，
      会自动重新准备。

  Q4: 没有独立显卡能用吗？
  A : 能。会自动使用 CPU 版，功能完全一样，只是推理慢一些。

  Q5: 我的显卡是 GTX 10 系（或更老）？
  A : 会自动使用 CPU 版并给出提示 —— 这类显卡的算力低于新版加速库支持的
      最低要求，强行用 GPU 会直接报错，用 CPU 是正确选择。

  Q6: 每次点"开始审计"都要等很久？
  A : 第一次审计要加载模型（几十秒到一两分钟），之后就快了。

  Q7: 报"文件超过 100MB 上限"？
  A : 拖拽上传的单个文件上限是 100MB。

  Q8: 顶部出现红色横幅"校准参数与模型可能不配套"？
  A : 说明 models 文件夹换得不完整。请确认 codebert_finetuned/ 与
      calibration_params.json 是同一次训练产出的，整体替换。

  Q9: 我的 API Key 存在哪？会上传吗？
  A : 存在本机 gui-settings.json。只有开启云端复核、且文件落在灰区时，
      才会把内容发给你配置的那个接口；其余情况不联网。


九、退出与清理
--------------------------------------------------------------------------------
  · 退出：关闭"CalibGuard"启动窗口即可（后端随之关闭）。
  · 清理运行痕迹：可删除 reports/、uploads/、logs/。
  · 彻底重装环境：删除 .venv/，下次启动自动重建。
  · 完全卸载：直接删除整个文件夹。
