从 Bench 交付新模型只需两个产物：results/{实验名}/codebert_finetuned/ 目录 + results/{实验名}/calibration_params.json（必须同一实验）。训练侧档案 （train.log / train_meta.json / hpo.json / eval_*.json / speed.json / identity_params.json / split_*.jsonl / error.log）留在 Bench 作实验追溯，本工具不消费。

  1. 退出 CalibGuard（关掉启动器窗口）。
  2. 把新版本的整个 models/ 目录覆盖到 exe 旁的 models/（codebert_finetuned/ 与 calibration_params.json 必须来自同一次训练，禁止拼凑）。
  3. 若新版本引擎代码有变（schema/管线变更），同时整体覆盖 calibguard/ 目录。
  4. 重启 CalibGuard；顶部红色横幅不出现即配套正常。
